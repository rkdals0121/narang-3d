# 나랑이 2.5D (시제품 0.1)

원본 그림을 그대로 쓰고, 그물망(48×48 격자)으로 휘어서 움직입니다. 3D 모델의 찰흙 느낌이나 색 차이가 없습니다.

- 정면: `나랑이.png` 4면 시트의 정면 (1024px로 키운 것)
- 엎드려 자기: `나랑이2.png` (검은 배경을 투명하게, 노란 빛 번짐은 남김)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 데모 페이지 (버튼으로 표정·동작·잠 시험) |
| `narang2d.js` | 엔진. 웹앱에 그대로 가져다 쓰는 모듈 |
| `assets/base.webp` | 눈·눈썹·입을 지운 나랑이 (70KB) |
| `assets/eye_l, eye_r, brow_l, brow_r, mouth.webp` | 원본에서 오려낸 눈·눈썹·입 |
| `assets/sleep.webp` | 엎드려 자는 그림 |
| `assets/layout.json` | 오려낸 부위의 위치 |
| `tools/build_2d.py` | 위 그림들을 원본에서 다시 만드는 스크립트 |

전체 약 0.4MB입니다 (3D 경량판은 1.07MB).

## 움직임

- **늘 하는 것**: 숨쉬기, 눈 깜빡임(가끔 두 번), 두리번거리기, 뿔과 잎사귀가 흔들림, 헤드셋과 하트 불빛이 숨쉬듯 깜빡임
- **고개 돌리기 (2.5D)**: 얼굴 가운데를 볼록한 돔으로 보고, 보는 방향으로 얼굴이 가장자리보다 더 많이 움직입니다. 뿔은 반대로 살짝 움직여 입체감이 납니다. 마우스나 손가락을 따라봅니다.
- **혼자 놀기**: 6~11초마다 태블릿 보며 두드리기, 들썩들썩, 윙크, 점프 중 하나
- **누르기**: 얼굴·몸을 누르면 점프(웅크렸다 늘어나는 탄성), 태블릿을 누르면 하트 눈과 하트가 뿅, 자는 중이면 깨어남
- **표정**: 웃음(원본 그대로), 크게 웃기, 윙크, 놀람, 슬픔, 하트 눈. 바뀔 때 부드럽게 섞입니다.
- **말하기**: 입이 말하듯 움직입니다 (안내 음성과 함께 쓰기)
- **잠**: 자기 1은 하품 → 눈이 감기며 고개를 떨굼 → Zzz. 자기 2는 그다음 밤하늘 배경으로 바뀌며 엎드린 그림으로 넘어갑니다. 깨우면 눈을 깜빡이며 깨어나 기지개를 켭니다.
- 시스템에서 "동작 줄이기"를 켠 사람에게는 움직임이 작아지고 혼자 놀기를 하지 않습니다.

## 웹앱에서 쓰기

```js
import { createNarang2D } from './narang2d.js';
const n = createNarang2D(document.getElementById('stage'), { assets: './assets/' });
n.setExpression('laugh');   // smile | laugh | wink | surprise | sad | love
n.jump(); n.love(); n.lookAtTablet(); n.wiggle();
n.talk(true);               // 말하는 입
n.sleep('sit');             // 자기 1 (앉아서)
n.sleep('lie');             // 자기 2 (엎드려, 밤 배경)
n.wake();
n.dispose();
```

옵션: `mood: 'sleep'`, `sleepPose: 'lie'`, `idle: false`(혼자 놀기 끄기), `tap: false`, `lookAtPointer: false`.
`#stage`는 크기가 있어야 합니다 (가로:세로 = 960:1130 권장).

## 한계

- 정면 그림이 4면 시트에서 오려 키운 것이라(원래 약 450px) 큰 화면에서는 조금 흐립니다. 더 큰 원본 파일이 있으면 바꿔 넣으면 됩니다(`tools/build_2d.py`).
- 360도 돌려보기는 안 됩니다. 정면 기준으로 좌우로 살짝 고개를 돌리는 정도입니다.
- 손을 크게 흔들거나 팔을 드는 동작은 없습니다. 가려진 부분을 새로 그려야 해서입니다.
- 앉은 모습과 엎드린 모습은 서로 다른 그림이라, 넘어갈 때는 잠깐 겹쳐서 바뀝니다.
- WebGL이 안 되는 기기에서는 휘는 효과 없이 위아래로 숨쉬기만 합니다.
