# 나랑이 2.5D (0.3, 포즈 추가)

웹앱에 그대로 넣는 마스코트 모듈입니다. 그림 위에 숨쉬기·깜빡임·흔들림을 입히고, 포즈 그림 사이를 "웅크렸다 통 튀어나오는" 동작으로 전환합니다.

- **기본 포즈**: 원본 `나랑이.png` 4면 시트의 정면. 표정(웃음·크게 웃기·윙크·놀람·슬픔·하트 눈)을 얼굴에 바꿔 그립니다.
- **포즈 5종**: 손인사, 만세, 길 안내(가리키기), 생각, 깜짝. 원본을 참고 이미지로 넣어 Canva AI로 같은 화풍으로 새로 만든 그림입니다.
- **잠**: 자기 1(앉아서, 원본에 감은 눈을 그림), 자기 2(엎드려, 원본 `나랑이2.png`, 밤 배경).

## 웹앱에서 쓰기

```js
import { createNarang2D } from './narang2d.js';
const n = createNarang2D(document.getElementById('stage'), { assets: './assets/' });

// 상황별 한 줄 (포즈 + 말풍선, 말이 끝나면 기본 포즈로 돌아옴)
n.hello('안녕하세요! 저는 나랑이예요.');      // 손인사
n.guide('출국장은 3층이에요. 이쪽으로 가요!'); // 길 안내 (오른쪽을 가리킴)
n.think('음… 탑승구를 찾아볼게요.');         // 생각 + 물음표
n.surprised('앗! 탑승까지 10분 남았어요!');   // 깜짝 + 느낌표
n.cheer('도장 하나 더 모았어요!');            // 만세 + 반짝이

// 직접 조절
n.setPose('point', 3);      // idle | wave | cheer | point | think | surprise, 3초 뒤 기본 포즈로 (0 = 유지)
n.setExpression('laugh');   // 기본 포즈의 표정: smile | laugh | wink | surprise | sad | love
n.say('문장');              // 말풍선만 (Promise: 닫히면 끝)
n.jump(); n.love(); n.nod(); n.shake(); n.lookAtTablet(); n.wiggle();
n.talk(true);               // 입만 움직이기 (안내 음성과 함께)
n.sleep('sit'); n.sleep('lie'); n.wake();
n.state;                    // { mode, pose, expression, busy, saying, ... }
n.dispose();
```

옵션: `mood: 'sleep'`, `sleepPose: 'lie'`, `idle: false`(혼자 놀기 끄기), `tap: false`, `lookAtPointer: false`, `onChange(state)`.
`#stage`는 크기가 있어야 합니다(가로:세로 = 960:1130 권장). 배경은 투명이라 페이지 배경 위에 얹힙니다.

## 움직임

- **늘 하는 것**: 숨쉬기, 눈 깜빡임(모든 포즈, 가끔 두 번), 두리번거리기, 뿔과 잎사귀 흔들림, 헤드셋·하트 불빛.
- **포즈별 부분 움직임**: 손인사는 손을 흔들고, 만세는 두 팔을 번갈아 들썩이고, 길 안내는 손가락으로 콕콕 가리키고, 생각은 고개를 천천히 갸웃합니다.
- **포즈 전환**: 지금 포즈가 웅크리는 순간 새 포즈로 바뀌고, 새 포즈가 통 튀어 오르며 출렁이다 멈춥니다. 바뀌는 순간 반짝이가 살짝 터집니다. 두 그림이 겹쳐 보이지 않습니다.
- **눈 깜빡임**: 포즈 그림에는 눈 밑 피부를 미리 만들어 둔 조각(`*_lids.webp`)이 있어서, 깜빡일 때 그 피부가 위에서 내려와 눈을 덮습니다. 얼굴 음영이 이어져 자국이 나지 않습니다.
- **혼자 놀기**: 6~11초마다 손인사, 생각, 태블릿 두드리기, 들썩들썩, 끄덕끄덕, 윙크, 점프 중 하나.
- **누르기**: 나랑이를 누르면 점프, 태블릿을 누르면 하트, 자는 중이면 깨어남.
- 시스템에서 "동작 줄이기"를 켠 사람에게는 움직임이 작아지고 혼자 놀기를 하지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `narang2d.js` | 엔진 (웹앱에 가져다 쓰는 모듈 하나) |
| `index.html` | 데모 페이지 |
| `assets/base.webp`, 눈·눈썹·입 조각, `layout.json` | 기본 포즈 (원본) |
| `assets/poses/*.webp`, `assets/poses.json` | 포즈 5종과 위치·눈·움직일 부위 정보 |
| `assets/poses/*_lids.webp` | 포즈별 눈꺼풀 피부 조각 |
| `assets/sleep.webp` | 엎드려 자는 그림 |
| `tools/build_2d.py`, `tools/build_poses.py`, `tools/raw_poses/` | 원본·생성 그림에서 위 파일을 다시 만드는 스크립트와 원본 포즈 그림(1264px) |

전체 약 0.8MB입니다.

## 포즈 더 넣기

1. 원본 정면과 4면 시트를 참고 이미지로 넣고, 같은 문장 틀로 포즈만 바꿔 생성합니다(흰 배경, 정면, 다리 없는 동그란 몸). 1264px 정사각형이면 그대로 맞습니다.
2. `tools/raw_poses/<이름>.png`로 넣고 `tools/build_poses.py`의 `P`에 눈 위치·발끝 높이·움직일 손을 적습니다.
3. `python tools/build_poses.py tools/raw_poses assets` → `n.setPose('<이름>')`.

만들어 두면 좋을 것: 사과(꾸벅), 하트 안기, 설명하기(손바닥 펴기), 엄지척, 졸기, 점프. 이번에는 Canva AI 사용량 한도에 걸려 만들지 못했습니다.

## 한계

- 새 포즈는 원본과 아주 똑같지는 않습니다(뿔이 조금 작고 모자 줄무늬가 가늚). 포즈끼리는 잘 맞습니다.
- 포즈 그림에서는 말할 때 입이 움직이지 않습니다(기본 포즈에서만 움직임).
- 길 안내는 오른쪽만 가리킵니다. 그림을 뒤집으면 뿔의 로고가 뒤집혀서 왼쪽 포즈는 따로 만들어야 합니다.
- 기본 정면 그림은 4면 시트에서 오려 키운 것이라(원래 약 450px) 큰 화면에서는 새 포즈보다 조금 흐립니다.
- WebGL이 안 되는 기기에서는 휘는 효과 없이 그림만 바뀌고 숨쉬기만 합니다.
